Swiggy Sales Analysis Project
Project Title: Swiggy Sales Analysis using Python
I developed a Swiggy Sales Analysis project to analyze food delivery sales data and identify key business
insights. The objective of the project was to understand customer ordering patterns, revenue trends, and
sales performance across different categories and locations.
For data analysis, I used Python with libraries such as Pandas and NumPy for data cleaning and
preprocessing. I used Matplotlib and Plotly to create interactive and visual charts for better business
understanding.
